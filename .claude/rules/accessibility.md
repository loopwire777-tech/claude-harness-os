# Accessibility

- Every interactive element must be reachable and operable by keyboard.
- Use semantic HTML elements before reaching for ARIA attributes.
- Every form input has an associated label.
- Every image has meaningful alt text, or `alt=""` if purely decorative.
- Maintain sufficient color contrast; never convey state by color alone.
- Preserve focus order and visible focus indicators.
