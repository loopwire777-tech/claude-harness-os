# Coding

- TypeScript strict mode; never weaken `strict` or use `any` to silence an error.
- No unused exports, variables, or imports.
- Prefer explicit return types on exported functions.
- Keep functions single-purpose; split when a function does more than one thing.
- No dead code, commented-out code, or TODO-and-abandon.
- Match existing naming and file conventions in the surrounding workspace.
- Don't add abstractions, config flags, or generalization for hypothetical future use.
